# 概述附件保留旧机制与正式文件留存（2026-10-18）

## 后续四项修补复核

- ECN 保存失败后改选内容：新内容使用新的归档 UUID，旧归档保留；确认后的名称及实际大小同步到附件元数据。
- 批量审批：项目状态变化导致排除时必须列出跳过项目，结果显示部分异常；执行进度和完整结果检查点均检查持久化是否成功，最终状态失败只重试保存，不重跑业务。
- 中断恢复：启动时恢复完整结果，否则转为中断待核对；页面允许有权限的审核人恢复已保存结果或填写核对说明归档。无法确认完成情况时禁止自动重跑，核对后仅为未完成目标另行申请。
- 新增与扩展回归位于 `test_overview_batch_recovery.py`、`test_information_batch_refresh.py`、`test_overview_file_choice.py`；本阶段跨模块 52 个模块、610 项测试全部通过，最终专项复测 26 项通过；真实 Pyright CLI 对 src/、tests/ 检查为 0 errors、0 warnings。未执行浏览器实点或真实共享盘测试，未修改通用数据库层。

## 最终业务决定

用户撤回“每份申请独立 UUID 副本”和“按名称、内容指纹共用库”两种新机制。涉及概述的文件保持原有命名、目录和同名选择语义；正式文件不因业务失败、回滚、删除引用、删除方案或整单而清理。旧文件不搬迁、不改名、不合并、不删除。先前报告中的 UUID 副本方案及其测试统计不再代表当前方案。

## 实施范围

- 普通概述上传：原文件名、原 URL、同名选择弹窗保留。提交期间出现同名文件时拒绝覆盖不同内容，而不是生成新编号。
- 批量概述：同名时弹窗选择使用已有文件、改名上传或取消，不再静默复用不同内容。选择已有文件时使用其内容作为送审快照；执行再次校验选择，保留正式文件。旧批量待审记录缺少选择信息时，只允许原名未占用或内容相同，否则要求重新提交。
- 普通及旧版纠错：原名保存；已有不同内容的同名文件要求改名，按已有文件名选择时直接引用。失败保留正式文件。保留 ECN 实际路径修复、内容指纹校验、旧页面防护及归档预览修复。
- 关键新增审批：暂存改为复制，不搬走可能已被引用的正式源文件。审批失败保留已发布文件和暂存源；成功后仅清理暂存。
- ECN 系统内资料：保留 UUID 送审归档，正式文件改为原名或用户确认的新名称。保存方案前检查正式目录同名文件，选择已有文件时归档已有内容。保存目录、文件名、来源和 SHA-256，执行复核，文件变化或消失即拦截；不覆盖、不恢复已删除文件。失败或删除方案/整单均保留 overview_ 归档和正式文件。ECN 未部署，不增加旧数据兼容。普通 ECN 附件清理规则未扩大修改。
- 原名安全发布使用同目录临时文件，完成写入并校验后发布；Windows 使用不覆盖目标的重命名，不依赖共享盘硬链接，其它平台使用硬链接。只删除本次尚未发布的临时文件。通用数据库层未改动。

## 回归范围

- tests/test_overview_file_retention.py：真实临时文件、并发同名同内容/不同内容、磁盘复制失败、旧同名选择、批量拒绝未经确认的不同内容、送审不搬走正式源、审批失败保留文件。
- tests/test_overview_file_choice.py：原名共享、选择已有文件后归档正确内容、正式文件删除/变化、目录变化、归档篡改、非法文件名、批量快照校验等 10 项回归。
- tests/test_overview_ecn_integration.py：保留实际路径修复与 ECN 占用交叉回归，将旧 UUID 副本断言改为原名保留及不回收；同时覆盖旧版纠错。
- tests/test_ecn_attachments.py：系统内资料归档失败留存、原路径重试，正式结果与归档在清理时保留；普通 ECN 附件测试继续执行。

测试仅操作临时目录/数据库，不读写清理正式附件，不发送外部通知。本轮未运行浏览器验收、真实共享盘/SMB 测试或断电测试。

## 上传机制清单（本轮未改其它业务）

| 功能 | 现有机制 |
| --- | --- |
| 普通概述、批量新增、普通纠错 | 原文件名；同名选择/复用；指纹仅校验 |
| ECN 系统内资料 | UUID4 送审归档，原名/确认名称正式发布或引用，SHA-256 内容校验 |
| ECN 其它附件 | UUID4 归档 |
| 需求附件 | 原名加 MD5 内容指纹 |
| 样品问题及措施附件 | 问题编号、上传人、原名、MD5 |
| 设计知识附件 | 知识类型、上传人、原名、MD5 |
| 头像 | 转换 PNG 后用户名加 UUID4 |
| 异常措施证据 | 有时间/随机编号保存函数，未找到当前 UI 调用，不能算在用入口 |
| 需求 JSON、身份权限配置包、样品单 Excel | 解析导入，不作为长期原始附件保存 |
| 物料匹配、像素统计、强度分布工具 | 上传内容用于内存计算，不作为长期附件保存 |
